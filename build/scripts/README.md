# Build Scripts

Build scripts will be added here as the Rebuilt Unix image builder is implemented.

Planned stages:

1. Prepare the FreeBSD 15.1 build environment.
2. Acquire the FreeBSD base system.
3. Assemble the target filesystem.
4. Install `pkg` and `sudo`.
5. Apply Rebuilt Unix configuration and branding.
6. Create a bootable amd64 image.
7. Run basic image validation.
