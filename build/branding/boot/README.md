# Rebuilt Unix Boot Artwork

This directory contains artwork intended for the Rebuilt Unix boot experience.

## Artwork policy

Boot artwork should be either:

- Original Rebuilt Unix artwork.
- Artwork whose license explicitly permits redistribution and modification.
- Artwork for which the project has permission to redistribute.

Do not add third-party BSD or Tux artwork here unless its applicable license and trademark requirements have been checked.

## Planned themes

- `rebuilt-unix.png` — primary Rebuilt Unix boot artwork.
- `freebsd-tux.png` — optional FreeBSD/Tux themed artwork, subject to licensing/trademark review.
- `openbsd-tux.png` — optional OpenBSD/Tux themed artwork, subject to licensing/trademark review.
- `netbsd-tux.png` — optional NetBSD/Tux themed artwork, subject to licensing/trademark review.

Image files will be consumed by the image-building stage once the bootloader/theme integration is implemented.
