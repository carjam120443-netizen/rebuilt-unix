# Tux Artwork Credits

The Tux artwork used by Rebuilt Unix is sourced from the `garrett/Tux` project:

- Original Tux artwork: Larry Ewing
- Vector redraw: Garrett LeSage
- Source: https://github.com/garrett/Tux

## BSD artwork

Official FreeBSD, OpenBSD, and NetBSD logos are not bundled here unless their respective usage terms permit redistribution in this project. The projects' official marks have separate trademark/copyright rules.

- FreeBSD logo: see the FreeBSD Project logo guidance.
- NetBSD logo: see the NetBSD Logo Usage Guidelines.
- OpenBSD artwork/logo: use only assets whose specific redistribution terms are clear.

For the default Rebuilt Unix boot artwork, use original Rebuilt Unix artwork together with the credited Tux asset rather than modifying or combining protected BSD logos.
