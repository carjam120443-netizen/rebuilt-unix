# Rebuilt Unix Branding

This directory contains branding owned by Rebuilt Unix or created specifically for the project.

## System branding

- `system/branding.conf` — centralized identity values
- `system/os-release` — OS identification
- `system/rebuilt-unix-version` — version information
- `system/rebuilt-unix-login.txt` — login/banner artwork
- `system/motd` — login message

## Visual branding

- `wallpapers/` — desktop and live-environment backgrounds
- `boot/` — bootloader artwork and theme configuration

The target system remains FreeBSD-based. Branding files change the presentation and identity of Rebuilt Unix without replacing FreeBSD's underlying kernel or core userland.
