# Rebuilt Unix

A custom Unix-based operating system built from FreeBSD.

## Base

- **Base OS:** FreeBSD 15.1-RELEASE
- **Architecture:** amd64 (initial target)
- **Package manager:** pkg(8)
- **Base system management:** FreeBSD packaged base (pkgbase)
- **Privilege escalation:** sudo

## Goals

Rebuilt Unix aims to keep the strengths of FreeBSD's base system and tools while developing its own branding, configuration, build process, and user experience.

The project is intentionally being developed in stages, starting with a minimal bootable system and expanding from there.

## Build

The initial build system will generate a reproducible amd64 image from the FreeBSD 15.1-RELEASE base.
